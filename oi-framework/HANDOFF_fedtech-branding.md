### How `lib.js` is structured

- **`THEME`:** heading font Cambria, body font Calibri, plus a palette. The colors are:
  - `dk1` 1A2B2E (ink)
  - `dk2`/`accent1` 0F4C4A (deep teal, dominant)
  - `lt2` EEF4F2 (mist)
  - `accent2` E8602C (coral accent)
  - `accent3` 2E8C7E (mid teal)
  - `accent4` F2B24C (amber, gates)
  - `accent5` 5F7376 (slate)
  - `accent6` BFE0D8 (mint)
- **`P`:** slides reference colors through these semantic names (`P.teal`, `P.coral`, `P.mint` and so on), which map to theme scheme colors. Changing `THEME.colors` therefore recolors every deck. `H` holds raw hex for shadows and backgrounds.
- **Three slide layouts (pptxgenjs masters):**
  - `Title Dark`
  - `Section Dark`
  - `Title Only`, which carries the footer text and the slide number
- **Footer:** `newDeck(title, { footer })` takes an optional footer. The NSF scripts already pass their own.
- **Shared drawing:** `drawFramework()` draws the one-page framework and `tracker()` draws the phase tracker. Both use the same palette.

## Build and QA steps (required)

```bash
cd oi-framework/build
npm init -y && npm install pptxgenjs react-icons react react-dom sharp
export NODE_PATH=$PWD/node_modules
export PPTX_SKILL=<path to the pptx skill directory>   # provides scripts/apply_theme.js and scripts/office/*
node client.js out.pptx   # each script writes the file, then runs applyTheme(out, THEME)
```

- **Load the pptx skill first.** It holds the pptxgenjs rules: no `#` in hex colors, `isTextBox: true`, never reuse option objects, run `applyTheme` after `writeFile`, and so on.
- **Rendering for QA needs extra packages.** It needs LibreOffice Impress and metric-compatible fonts, which may be missing:
  `apt-get install -y libreoffice-impress fonts-crosextra-carlito fonts-crosextra-caladea`
- **Convert with the skill's wrapper:**
  `python $PPTX_SKILL/scripts/office/soffice.py --headless --convert-to pdf --outdir <dir> <abs path>.pptx`
  then `pdftoppm -jpeg -r 70`. Use absolute paths; relative paths failed in the previous session.
- **Validate every output:** `python $PPTX_SKILL/scripts/office/validate.py deck.pptx`.
- **Check every slide image visually** for overflow, overlaps, logo collisions, and contrast of any new brand color on white and on the dark layouts. Amber on white was already found to be unreadable for text.
- **Font caveat:** if FedTech's brand font is outside the safe list (Arial, Calibri, Cambria, Times New Roman, Courier New, Bookman Old Style, Century Schoolbook), LibreOffice previews will be approximate. Leave about 10% text slack, or use a safe fallback for body text.
- **Don't regress the neutral decks.** Rebuild the neutral decks and confirm their text is unchanged: `markitdown` diff before and after.
